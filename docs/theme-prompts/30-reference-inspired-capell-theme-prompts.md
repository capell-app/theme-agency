# 30 Reference-Inspired Capell Theme Prompts

These prompts are written to borrow design direction, not identity. Use them to generate original Capell themes with distinct names, assets, color tokens, typography choices, and component details.

## 1. Awwwards-Inspired: Experimental Directory Theme

Create an editorial directory theme for a creative industry site. Use a pale neutral background, dense modular rows, oversized project titles, compact metadata, visible scoring/status badges, and large image-led feature blocks. The theme should feel like a curated awards index: high contrast, crisp grid rules, tight spacing, and confident typography. Include sections for featured item, latest entries, collections, profiles, and learning/resources. Avoid copying any brand marks or exact layouts; make the system suitable for agencies, studios, architects, and portfolio-heavy CMS sites.

## 2. The FWA-Inspired: Motion Archive Theme

Design a digital-awards archive theme with an industrial editorial feel. Use a muted grey canvas, black typography, condensed headings, filter-heavy navigation, date archives, and large visual cards that feel ready for motion previews. The layout should support chronological browsing, winner profiles, point systems, and project metadata. Prioritize fast scanning: sticky filters, compact category chips, and repeatable card/list hybrids. Keep the tone bold and technical without becoming decorative.

## 3. Godly/Recent-Inspired: Minimal Curation Feed Theme

Create a minimal inspiration-feed theme for daily curated links, screenshots, and product references. Use a white background, system sans typography, small labels, lightweight borders, and a masonry-like stream of compact visual entries. The homepage should feel current and calm: short intro copy, category tabs, live/update indicators, and a newsletter module. Make imagery and screenshots the primary content, with text restrained to titles, authors, ratings, and tags.

## 4. Brutalist Websites-Inspired: Raw Index Theme

Design a deliberately raw CMS theme for art, music, underground culture, or experimental publishing. Use monospace typography, plain grey or white backgrounds, visible browser-default-inspired links, minimal spacing polish, and a long, irregular index of entries. The theme should look intentionally unfiltered but still be accessible and responsive. Include support for images, interviews, submission links, ads/sponsors, and chronological lists. Avoid fake nostalgia; make the roughness purposeful.

## 5. CSS Design Awards-Inspired: Scoreboard Showcase Theme

Create a design-awards theme built around rankings, nominations, and judging. Use a warm off-white background, compact uppercase labels, numeric scores, segmented evaluation criteria, and strong horizontal rhythm. The homepage should feature a winner of the day, newest nominees, previous winners, and score breakdowns. Cards should combine image, date, category, and metrics in a tidy editorial system. The mood should be authoritative, international, and competition-ready.

## 6. SiteInspire-Inspired: Quiet Web Gallery Theme

Design a calm web-design gallery theme that prioritizes browsing by style, type, and category. Use light grey backgrounds, modest typography, small serif accents, and practical navigation blocks. The page should feel mature and useful rather than flashy: browse panels, recent additions, sponsor area, comments, and category archives. Keep the visual language understated so showcased work can carry the personality.

## 7. Web Design Inspiration-Inspired: Filter-Rich Gallery Theme

Create a broad inspiration-library theme with a clean white canvas, Inter-style typography, high-density filter menus, and thumbnail-led grids. The design should support many taxonomies: industry, style, color, platform, and content type. Include prominent search, editorial picks, latest designs, blog modules, and FAQ/mission content. Make the system scalable for thousands of entries while keeping the interface approachable and modern.

## 8. Land-book-Inspired: Polished Landing Gallery Theme

Design a polished landing-page gallery theme for SaaS, ecommerce, and startup inspiration. Use a warm near-white background, rounded image cards, refined spacing, and a productized navigation with sections for websites, templates, components, mobile, and motion. The hero should include a concise value proposition and search/filter controls. Card metadata should feel premium but compact: title, category, votes, comments, price, or platform tags.

## 9. Lapa Ninja-Inspired: Resource Hub Theme

Create a landing-page inspiration and education hub. Use a bright white layout, crisp sans typography, clear category navigation, and stacked sections for website examples, social images, templates, courses, books, and learning resources. The homepage should feel useful immediately: large search, category shortcuts, recent examples, and resource cards. Keep the aesthetic friendly, practical, and content-rich without looking like a generic blog.

## 10. One Page Love-Inspired: One-Page Showcase Theme

Design a curated one-page website showcase theme. Use warm text colors, spacious cards, compact tags, and a friendly editorial voice. The homepage should feature a large human headline, count-based social proof, category filters, and a grid of shipped one-pagers. Build strong support for templates, sections, tools, and sponsored recommendations. The system should feel indie, efficient, and maker-oriented.

## 11. Stripe-Inspired: Premium Infrastructure Theme

Create a premium B2B SaaS theme for complex infrastructure products. Use large, confident display typography, layered product UI mockups, subtle gradients used sparingly, and modular sections for solutions, global scale, developer tools, case studies, and news. The theme should communicate trust, technical depth, and commercial maturity. Include strong CTA pairs, code/product panels, metrics, and multilingual/global cues. Do not copy Stripe’s colors or illustrations; translate the quality bar into an original system.

## 12. Linear-Inspired: Dark Product System Theme

Design a dark, product-led SaaS theme for teams, workflows, and technical operations. Use a near-black background, refined grey borders, soft glows only where functional, crisp Inter-like typography, and detailed product interface compositions. The hero should show the product as a working system, not decoration. Include sections for workflows, agents/automation, roadmap, changelog, integrations, and customer proof. Motion should feel precise and restrained.

## 13. Vercel-Inspired: Developer Infrastructure Theme

Create a minimal developer platform theme with a white or near-white foundation, black typography, mono labels, sharp dividers, and diagram-like sections. The homepage should split the product story into two or three core pillars with technical feature lists. Use restrained cards, command/code blocks, status indicators, deployment timelines, and enterprise CTAs. The aesthetic should be exact, fast, and engineering-led.

## 14. Framer-Inspired: Interactive Builder Theme

Design an expressive product theme for a visual builder or creative tool. Use a dark hero, high-contrast UI mockups, floating canvas panels, colorful media strips, and section transitions that feel interactive. The copy areas should be short and dramatic, while the visuals show workflows, layers, assets, publishing, and collaboration. Include customer showcase, platform capabilities, community, and final CTA sections. Keep it original by inventing a new visual language for the canvas and controls.

## 15. Attio-Inspired: Editorial CRM Theme

Create an editorial SaaS theme for a modern revenue or operations platform. Use refined typography, generous whitespace, product-first hero imagery, subtle neutral tones, and crisp CRM-style interface modules. The theme should feel polished and strategic rather than loud. Include sections for data model, workflow automation, team collaboration, integrations, customer stories, and flexible dashboards. Use elegant cards, fine borders, and strong hierarchy.

## 16. Bestfolios-Inspired: Portfolio Directory Theme

Design a portfolio showcase theme for designers, developers, and studios. Use a clean white canvas, energetic accent color, large preview tiles, and simple filtering by role, medium, or style. The homepage should feel like a useful directory with curated lists, featured portfolios, resume resources, and inspiration categories. Emphasize thumbnails, concise descriptions, and creator metadata.

## 17. Dribbble-Inspired: Creative Marketplace Theme

Create a creative marketplace theme for hiring designers and browsing visual work. Use a bright, friendly interface, rounded thumbnails, expressive category chips, and a hero that cycles through service categories. Support profiles, services, briefs, shots, agencies, and hiring CTAs. The design should feel social and energetic while preserving enough structure for real marketplace workflows.

## 18. Behance-Inspired: Case Study Platform Theme

Design a creative portfolio platform theme focused on rich case studies. Use a light neutral background, wide editorial grids, bold creator-focused headlines, and strong filters across disciplines. Project cards should support appreciations, views, ownership, media type, and category. Include a hero for creators, talent discovery, project feeds, assets, and hiring. Make the visual system broad and professional enough for many creative fields.

## 19. Killer Portfolio-Inspired: Characterful Portfolio Index Theme

Create a curated portfolio index theme with personality. Use a soft off-white or pale lavender background, friendly sans typography, short editorial blurbs, and cards that highlight why each portfolio works. The site should support filters for personal, company, design, development, and video portfolios. The tone should be selective, useful, and slightly playful, with enough restraint to let examples shine.

## 20. Awwwards Portfolio-Inspired: Premium Portfolio Collection Theme

Design a premium portfolio collection theme for personal sites and studios. Use a clean awards-style grid, large previews, filters for category/tag/technology/country/font/color, and strong editorial intro copy. Include featured portfolios, newest entries, most-awarded profiles, and educational upsells. The system should feel aspirational and gallery-like, but avoid copying any specific award-site branding.

## 21. It’s Nice That-Inspired: Creative Editorial Theme

Create a culture and design editorial theme with strong art direction. Use a mix of elegant serif and modern sans typography, bold category labels, large image-led stories, and a homepage that balances feed freshness with magazine structure. Include sections for projects, opinion, advice, culture, must-reads, events, newsletters, and tag browsing. The mood should be smart, warm, and creatively literate.

## 22. New York Times-Inspired: Dense News Theme

Design a serious news and analysis theme with dense hierarchy. Use a white background, classic serif headlines, compact sans metadata, fine rules, and multi-column story layouts. Support live labels, top stories, missed-it sections, video rows, opinion, sports, and topic navigation. The theme should prioritize trust, scanability, and editorial discipline over visual novelty.

## 23. Monocle-Inspired: Premium Global Magazine Theme

Create a premium magazine theme for global affairs, travel, culture, and design. Use refined serif typography, restrained black-and-white structure, confident section headers, and a blend of editorial, audio, guide, and shop modules. The layout should feel worldly and commercially polished. Include columnists, city guides, radio/audio blocks, latest stories, books, travel, and newsletter signup.

## 24. Wallpaper-Inspired: Design-Led Magazine Theme

Design a design, interiors, architecture, and fashion editorial theme. Use elegant serif headlines, clean sans navigation, generous image crops, and a homepage built around latest news, editor picks, vertical categories, and newsletter conversion. The mood should be refined, international, and visually literate. Let photography dominate while keeping typography quiet and precise.

## 25. Figma Blog-Inspired: Product Editorial Theme

Create a product-company editorial theme with a dark masthead, playful yet disciplined typography, topic labels, author/date metadata, and strong story cards. The homepage should support featured posts, product updates, engineering/design essays, template stories, and newsletter signup. Include subtle mono accents for technical content and flexible card sizes for editorial rhythm.

## 26. Apple-Inspired: Product Storytelling Theme

Design a polished product storytelling theme for a premium consumer brand. Use expansive full-width product sections, centered headlines, minimal navigation, large photography or renders, and clean CTA pairs. The homepage should move through hero, product families, feature highlights, trade-in/promo modules, and entertainment or ecosystem content. Keep the visual system simple, spacious, and immaculate without copying Apple’s assets, phrasing, or exact composition.

## 27. Nike-Inspired: Bold Commerce Campaign Theme

Create a high-energy ecommerce campaign theme for sport, fashion, or events. Use large photographic heroes, uppercase condensed headings, strong black-and-white contrast, category panels, and quick shop CTAs. The homepage should support seasonal campaigns, collection launches, kids/men/women segmentation, icons/products, and community discount modules. The tone should be active, confident, and direct.

## 28. Aesop-Inspired: Restrained Luxury Retail Theme

Design a restrained luxury retail theme for skincare, fragrance, hospitality, or boutique products. Use warm neutrals, generous whitespace, serif/sans contrast, quiet navigation, editorial product descriptions, and carefully paced imagery. Product cards should feel tactile and calm, with ingredient/story modules, store consultation blocks, and considered cross-sells. Avoid copying Aesop’s exact palette or prose; preserve the discipline and quiet confidence.

## 29. Patagonia-Inspired: Mission Commerce Theme

Create an outdoor commerce theme that combines product categories with activism and storytelling. Use sturdy sans typography, natural imagery, practical navigation, and strong modules for collections, sports, environmental campaigns, stories, and newsletter signup. The homepage should balance shopping with values: featured gear, hot-weather essentials, action campaigns, latest stories, and durable product language. The visual tone should be rugged, clear, and principled.

## 30. COS-Inspired: Minimal Fashion Retail Theme

Design a minimal fashion retail theme with restrained typography, full-bleed editorial photography, black-and-white navigation, and sparse product/category CTAs. The homepage should prioritize seasonal collections, women/men paths, newsletter signup, craft/features, store locator, and product care. Use a calm grid, generous margins, and quiet interaction states. The result should feel elevated and contemporary, not empty.
