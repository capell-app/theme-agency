# 30 Reference-Inspired Capell Theme Prompts

These prompts are written to borrow design direction, not identity. Use them to generate original Capell themes with distinct names, assets, color tokens, typography choices, and component details.

Each prompt assumes a complete Capell public theme: homepage, inner content pages, index/archive views, detail pages, reusable widgets, responsive navigation, footer, forms, pagination, search/filter states, and editor-safe public Blade output.

## 1. Awwwards-Inspired: Experimental Directory Theme

Create an editorial directory theme for creative industry sites. Use a pale neutral canvas, confident black text, tight grid rules, oversized project titles, compact metadata, status badges, and large image-led feature blocks. Build the homepage around a "featured today" hero, latest submissions, winners, collections, profiles, resources, and sponsor modules. Typography should use a condensed or tight grotesk for headings, small uppercase labels for metadata, and dense but readable body copy. Cards should alternate between wide image slabs, list rows, and compact profile tiles. Add tasteful hover states: image lift, metadata reveal, quick category filters, and score chips. Keep it suitable for agencies, studios, architecture practices, artists, and portfolio-heavy CMS sites without copying any awards branding.

## 2. The FWA-Inspired: Motion Archive Theme

Design a digital-awards archive theme with an industrial editorial feel. Use a muted grey canvas, black typography, condensed headings, left-side filters, date archives, and large visual cards that feel ready for video or motion previews. The page rhythm should be archive-first: month/year filter rail, winner list, featured project panel, jury/score explanations, and a compact footer of historical links. Use sharp rectangular media frames, small numeric counters, and pill-free tags that feel more like technical labels. Detail pages should include synopsis, credits, technology stack, awards, media gallery, and next/previous projects. Motion should be restrained: preview scrub on hover, filter drawer slide, and subtle page transitions.

## 3. Godly/Recent-Inspired: Minimal Curation Feed Theme

Create a minimal inspiration-feed theme for daily curated links, screenshots, apps, and product references. Use a white background, system sans typography, hairline borders, tiny labels, and a loose masonry or column feed. The hero should be short: one sentence, a live/update indicator, category tabs, search, and newsletter signup. Entries should prioritize screenshots with just enough metadata: title, maker, source, rating, platform, and topic tags. Keep spacing airy but not precious, with compact mobile cards and an infinite-feed-friendly archive. Include "best of", "latest", "apps", "websites", and "icons" views. The theme should feel current, calm, and fast.

## 4. Brutalist Websites-Inspired: Raw Index Theme

Design a deliberately raw CMS theme for art, music, underground culture, experimental publishing, or independent archives. Use monospace typography, plain grey or white backgrounds, blue/underlined or stark black links, minimal decoration, and a long irregular index of entries. Let images appear at inconsistent but controlled sizes, as if the content is pinned into an archive wall. Add accessible roughness: visible focus outlines, simple forms, obvious skip links, and responsive single-column fallbacks. Include submission links, interview markers, ads/sponsors, archive dates, and optional language or zine-style annotations. Avoid fake nostalgia; the roughness should be purposeful, readable, and fast.

## 5. CSS Design Awards-Inspired: Scoreboard Showcase Theme

Create a design-awards theme built around rankings, nominations, and judging. Use a warm off-white background, compact uppercase labels, numeric scores, segmented evaluation criteria, and strong horizontal rhythm. The homepage should feature a winner of the day, newest nominees, previous winners, and score breakdowns for UI, UX, innovation, and overall rating. Cards should combine image, date, country, category, judge score, and voting CTA in a tidy editorial system. Detail pages should include hero media, score table, creator credits, related winners, and public voting/status states. Use precise microinteractions: score bars animate once, nominee cards reveal criteria on hover, and filters stay sticky.

## 6. SiteInspire-Inspired: Quiet Web Gallery Theme

Design a calm web-design gallery theme that prioritizes browsing by style, type, and category. Use light grey backgrounds, modest sans typography, small serif accents, practical navigation blocks, and understated image grids. The homepage should include four utilitarian panels: browse, follow/subscribe, submit, and blog, followed by latest showcase entries and sponsor space. Use small captions, dates, categories, and comments instead of large promotional copy. Inner pages should support category archives, random picks, "best of" lists, and simple editorial posts. Keep the visual language quiet so showcased work can carry personality.

## 7. Web Design Inspiration-Inspired: Filter-Rich Gallery Theme

Create a broad inspiration-library theme with a clean white canvas, Inter-style typography, high-density filter menus, and thumbnail-led grids. The design should support many taxonomies: industry, style, color, platform, content type, and technology. The homepage needs prominent search, editor picks, latest designs, blog modules, mission content, FAQ, and alphabetized/category mega menus. Use expandable filter groups, selected-filter chips, saved views, and pagination that handles thousands of entries. Cards should have consistent aspect ratios, clear category labels, and quick actions. Make it scalable and practical without looking like a database admin screen.

Keep the system premium and highly reusable for Capell marketplace/demo content.

## 9. Lapa Ninja-Inspired: Resource Hub Theme

## 10. One Page Love-Inspired: One-Page Showcase Theme

Keep border radii modest, use clear empty states, and make mobile browsing feel like a polished catalog rather than a blog roll.

## 11. Stripe-Inspired: Premium Infrastructure Theme

Include CTA pairs, metrics strips, customer logo rows, code/product split sections, global map or localization cues, and trust/compliance modules. Use color as an accent system rather than decoration. Do not copy Stripe's colors or illustrations; translate the quality bar into an original visual language.

## 12. Linear-Inspired: Dark Product System Theme

## 13. Vercel-Inspired: Developer Infrastructure Theme

## 14. Framer-Inspired: Interactive Builder Theme
