## What this theme gives you

An awards-style portfolio directory look. It gives your site a curated, recognition-led direction for featured work.

## How to use it

1. Open the theme-management entry for **Theme Agency**, note the site's current theme, and select only the site you intend to review.
2. Choose **Preview Theme Agency** to view this theme privately on that site's existing content without changing its selected theme. Check available page areas, sections and the mobile layout; create a page first if there is nothing to preview.
3. When ready, choose **Apply Theme Agency** for that site. This changes its public design immediately, including already-published pages.
4. Use the shared Theme Studio editor to choose an available preset and adjust the standard theme controls.
5. Build the page with the theme's Layout Builder sections.
6. Review the saved page on desktop and mobile, including keyboard navigation.

To recover the previous design, reopen the previous theme's management entry, select the same site and choose its **Apply** button. This restores the theme selection; it does not undo content or shared Theme Studio settings. Saving those settings can affect public pages using that theme, so do not treat settings edits as private preview changes.

## What it adds

- Featured portfolios, newest entries, and winner labels.
- Taxonomy filters, creator profiles, and educational resources.
- Newsletter sections and portable demo content.

## Good to know

- Built on **Foundation Theme** - install that first.
- Private theme preview keeps the current site theme selected until you choose **Apply**.
- Your text and images stay yours; the theme only changes the design.

## Try fictional demo content safely

Use private theme Preview for existing content. Ask a developer to follow [safe demo setup](../../theme-foundation/docs/demo-setup.md) in a disposable local site when you want fictional sample pages instead.

A scoped demo run writes sample pages, widgets and demo layouts, including on repeats, and can adopt the site recovery page. An unscoped run refuses existing sites; a scoped run preserves site configuration unless the developer deliberately chooses the documented overwrite option. Review the target, languages and domains together before setup.
