## What this theme gives you

A focused look for newsletter creators and solo media brands. It gives your site a clean, subscribe-first direction.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Creator Newsletter** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Page styles suited to a newsletter or solo media site.
- Portable demo content to start from.
- Colours and fonts tuned for the creator look, all editable in Theme settings.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Pairs well with Newsletter for sign-ups and sends.
