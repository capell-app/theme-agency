# Using Comments

This guide is for editors who moderate comments and owners deciding the moderation policy. Every step uses the labels you see on screen.

## Using Comments (editor how-to)

### How to approve or hide a comment

1. Go to the **Moderation inbox**.
2. Read each waiting comment.
3. Click **Approve** to make it appear, or hide it if it doesn't belong.

### How to reply to a comment

1. Open the comment.
2. Use **Reply** to respond directly from the admin.
3. Save. Your reply appears under the comment.

### How to mark spam

1. In the inbox, open the unwanted comment.
2. Click **Mark spam**.
3. It is removed and helps filter similar comments.

### How to add a moderator note

1. Open a comment and add a **Moderator note**.
2. This is for your team only and isn't shown to visitors.

## Rolling out Comments (for owners)

### Turn on first

- **Pre-moderation (approve before it appears).** Start by approving every comment so nothing unwanted is ever live, then relax later if you wish.

### Add when needed

| Need | Enable |
| --- | --- |
| Less manual work as trust grows | Post-moderation (comments appear, then you review) |
| Stay within your privacy policy | A comment retention period |

### Don't enable yet

- Don't let comments appear without review on a new site. Start with pre-moderation.

### Who does what

| Role | First useful screen |
| --- | --- |
| Editor / moderator | **Moderation inbox**: approve, hide, reply |
| Site owner | Settings: moderation mode and retention |

## Troubleshooting for editors

| What you see | What it means | What to do |
| --- | --- | --- |
| A comment isn't showing on the site | It isn't approved yet | Open the **Moderation inbox** and **Approve** it |
| Spam keeps appearing | Spam isn't being filtered | **Mark spam** on the offenders to improve filtering |
| Comments aren't available on a page | Commenting is off for that content | Confirm comments are enabled for that content type |
| Old comments need removing | Retention period not set | Set how long comments are kept |
