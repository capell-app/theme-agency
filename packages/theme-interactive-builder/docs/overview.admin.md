## What this theme gives you

A colourful look for interactive builder and canvas products. It gives your site a playful, product-led direction tuned for creative tools.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Interactive Builder** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Canvas workspaces, builder capabilities, and templates.
- Collaboration, community showcases, and publishing controls.
- Colourful media strips and helper panels with portable demo content.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Your text and images stay yours; the theme only changes the design.
