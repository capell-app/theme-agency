# Using Media AI

This guide is for editors who improve images. Every step uses the labels you see on screen.

## What you're looking at

| Screen or signal | What it tells you |
| --- | --- |
| **Doctor image** | The tool to enhance or analyse an image |
| "Request queued" | Your request is processing; wait a moment |
| Compare view | The improved image next to the original |

## What to do when...

| Situation | What to do |
| --- | --- |
| You want to improve an image | Open it and click **Doctor image** |
| The result looks better | Compare with the original, then replace the image |
| The result looks worse | Keep the original; don't replace it |
| A request is taking a while | It is queued; give it a moment to complete |

## Settings and retention

- Always compare before replacing, so you keep the original if the result isn't an improvement.
- Doctor requests may run in the background and complete shortly after you start them.
