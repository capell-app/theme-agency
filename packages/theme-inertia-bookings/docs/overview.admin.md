## What this theme gives you

A premium, app-like look for booking businesses: services, clinics, consultants, classes, and appointments. It gives your site a smooth, modern booking experience.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Theme Inertia Bookings** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- A polished booking-business front end with portable demo content.
- Colours and fonts tuned for the booking look, all editable in Theme settings.

## Good to know

- Built on **Foundation Theme** - install that first.
- Needs Capell Inertia and a framework component pack (React or Vue), plus Bookings for appointments.
- **Preview** to see it before visitors do.
