# Equestrian Clinics

Equestrian Clinics is the Capell package for full equestrian operations: Tour Days, private and group clinic slots, venues, riders, horses, waivers, payments, credits, facility resources, host requests, and coach-ready day-of workflows.

It is built as a vertical package on top of Bookings, Events, Payments, Customer Portal, Address, and Media Library. Generic scheduling stays generic; equestrian rules live here.

## What It Adds

| Area              | Capability                                                                                                                                             |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Tour days         | Venue-linked clinic days, operating hours, slot templates, auto-generation, private/semi-private/group capacity, and minimum viable clinic thresholds. |
| Discovery         | Calendar, venue filtering, nearest-event search, open-slot demand heatmap, and host/request-an-event forms.                                            |
| Payments          | Stripe, PayPal, deposits, refunds, checkout holds, approved cash customers, universal booking fee, and guarded legal-mode method fees.                 |
| Riders and horses | Family accounts, rider skill tiers, medical and emergency data, horse suitability, vaccinations, and workload limits.                                  |
| Facilities        | Arenas, fields, paddocks, stables, horseboxes, hookups, equipment, add-ons, conflict checks, and facility reports.                                     |
| Coach workflow    | Mobile timetable, rider/horse quick view, attendance, no-shows, broadcasts, coaching vault, notes, homework, and rebooking.                            |
