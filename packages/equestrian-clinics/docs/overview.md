# Equestrian Clinics

<!-- prettier-ignore-start -->

## What it does for you

Equestrian Clinics lets you run riding clinics and group sessions. You set up a clinic with a date and capacity, let riders request a slot or host a clinic, and manage who is attending. It is a specialist add-on for equestrian sites.

## Your screens

- **Clinics**: your clinics and sessions, with dates and capacity.
- **Attendees**: who is attending each clinic.
- **Requests**: riders asking to join or host a clinic.

## What you can do

- Set up a clinic with a date and capacity.
- Choose the clinic type (for example a group clinic).
- Manage who is attending.
- Handle requests to join or host.

## Where to find it

Go to **Equestrian Clinics** in the admin to set up clinics and manage attendees.

## Good to know

- Set up a **clinic** with a date and capacity so it can be booked.
- Manage who is **attending**, and watch the minimum and maximum numbers.
- Enable this only on sites that actually run clinics.
