# Using Equestrian Clinics

This guide is for staff who run clinics and owners deciding whether to enable this specialist add-on. Every step uses the labels you see on screen.

## Using Equestrian Clinics (editor how-to)

### How to set up a clinic

1. Go to **Equestrian Clinics**.
2. Create a clinic and set its date, **Clinic type**, and capacity.
3. Set the minimum and maximum number of attendees.
4. Save. Riders can now request a slot.

### How to manage attendees

1. Open the clinic's **Attendees**.
2. See who has joined against the minimum and maximum.
3. Add or remove attendees as needed.

### How to handle requests to join or host

1. Open **Requests**.
2. Review riders asking to **Request this slot** or to host a clinic.
3. Accept or decline each request.

## Rolling out Equestrian Clinics (for owners)

### Turn on first

- **One clinic with a clear date and capacity.** Run a single clinic end to end before scheduling many.

### Add when needed

| Need                       | Enable             |
| -------------------------- | ------------------ |
| Group sessions             | Group clinic types |
| Let riders propose clinics | Host requests      |

### Don't enable yet

- Enable this only on sites that actually run equestrian clinics. It is a niche add-on.

### Who does what

| Role             | First useful screen                         |
| ---------------- | ------------------------------------------- |
| Clinic organiser | **Clinics** and **Attendees**               |
| Site owner       | Decide whether clinics are part of the site |

## Troubleshooting for editors

| What you see                 | What it means                               | What to do                                    |
| ---------------------------- | ------------------------------------------- | --------------------------------------------- |
| A clinic can't be booked     | Its date or capacity isn't set              | Open the clinic and set its date and capacity |
| A clinic won't run           | It is below the minimum number of attendees | Promote it, or adjust the minimum             |
| A rider can't request a slot | The clinic is full or not open for requests | Check capacity and that requests are open     |
