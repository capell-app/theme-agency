## What it does

Public Actions lets approved external tools and AI assistants read or trigger certain site actions in a controlled way.

## Do I need to do anything?

Usually no. It works behind the scenes once installed and configured. You will see its effect when an approved external tool performs an allowed action.

## Where it shows up

It does not add a screen you operate day to day. Its effect appears when connected tools use the actions it exposes.

## Good to know

- This connects external tools to your site, so leave its setup to someone who manages integrations.
- Only approved actions are exposed; ask your developer before connecting a new tool.
