## What this theme gives you

A clean, data-confident look for AEO and GEO analytics products, brand-visibility tools, and analytics SaaS. It dresses your site in a focused, modern direction without a design project.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **AEO Analytics** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- A tailored set of page styles for an analytics product site.
- Portable demo content to start from.
- Colours and fonts tuned for the analytics SaaS look, all editable in Theme settings.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Your text and images stay yours; the theme only changes the design.
