# URL Manager

<!-- prettier-ignore-start -->

## What it does for you

URL Manager keeps your links working. When a page moves or a URL changes, you send the old address to the new one with a redirect, so visitors and search engines always land in the right place. You can fix one link at a time or import many at once.

## Your screens

- **Redirects**: the list of redirects you have set up.
- **404 opportunities**: pages visitors couldn't find, ready to redirect.
- **Import**: the tool for adding many redirects from a spreadsheet.

## What you can do

- Create a redirect from an old URL to a new one.
- Fix a link that moved.
- Import many redirects at once.
- Turn a 404 into a redirect.
- Export your redirects.

## Where to find it

Go to **URL Manager** in the admin to manage redirects and review 404s.

## Good to know

- Send an old URL to its new home with a **redirect**, so visitors don't hit an error.
- Turn a **404 opportunity** into a redirect to recover lost visitors.
- Avoid redirect **loops** (A points to B and B points back to A).
