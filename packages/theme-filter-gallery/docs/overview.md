# Theme Filter Gallery

<!-- prettier-ignore-start -->

## What this theme gives you

A clean, broad inspiration-library look with dense filtering. It gives your site a browse-first direction for large collections.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Filter Gallery** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Dense taxonomy filters, selected-filter chips, and saved views.
- Category mega menus, editor picks, and latest designs.
- Blog modules, FAQ, and scalable pagination with portable demo content.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Your text and images stay yours; the theme only changes the design.
