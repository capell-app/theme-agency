# Password Policy

<!-- prettier-ignore-start -->

## What it does for you

Password Policy lets you set how strong passwords must be and block known-compromised ones. You set the rules, and you can require people to change their password.

## Your screens

- **Password policy settings**: the rules for new passwords.

## What you can do

- Set a minimum password length.
- Block known-compromised passwords.
- Require a user to change their password.

## Where to find it

Go to **Password Policy** in the admin settings.

## Good to know

- Set how strong passwords must be with **Minimum password length**.
- Turn on **Block compromised passwords** to reject ones found in known breaches.
- Tell your team before tightening rules, so the change doesn't surprise them.
