# Using Password Policy

This guide is for owners and operators who set password rules. Every step uses the labels you see on screen.

## What you're looking at

| Screen or signal | What it tells you |
| --- | --- |
| **Minimum password length** | How long passwords must be |
| **Block compromised passwords** | Whether known-breached passwords are rejected |
| **Must change password** | A user is required to set a new password |

## What to do when...

| Situation | What to do |
| --- | --- |
| You want stronger security | Raise the **Minimum password length** and enable **Block compromised passwords** |
| You're tightening rules | Tell your team first; existing passwords may need changing |
| An account may be at risk | Set **Must change password** for that user |
| Someone is locked out | Confirm the rules and help them set a compliant new password |

## Settings and retention

- Communicate rule changes before applying them, so users aren't caught out at their next login.
- Blocking compromised passwords checks against known breaches without storing the password itself.
