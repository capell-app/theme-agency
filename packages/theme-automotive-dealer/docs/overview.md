# Theme Automotive Dealer

<!-- prettier-ignore-start -->

## What this theme gives you

A bold, showroom look for car dealerships and used-car retailers. It gives your site a confident retail direction tuned for selling vehicles.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Automotive Dealer** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Page styles suited to a vehicle dealership site.
- Portable demo content to start from.
- Colours and fonts tuned for the dealership look, all editable in Theme settings.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Your text and images stay yours; the theme only changes the design.
