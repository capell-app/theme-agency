# Theme API Platform

<!-- prettier-ignore-start -->

## What this theme gives you

A developer-focused look for API products and voice, auth, or infrastructure platforms. It gives your site a technical, trustworthy direction tuned for developer audiences.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **API Platform** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Page styles suited to a developer API product site.
- Portable demo content to start from.
- Colours and fonts tuned for the API platform look, all editable in Theme settings.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Your text and images stay yours; the theme only changes the design.
