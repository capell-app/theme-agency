# Theme Healthcare

<!-- prettier-ignore-start -->

## What this theme gives you

A calm, conversion-focused look for clinical and healthcare sites. It routes patients toward the right enquiry with clear, reassuring styling.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Theme Healthcare** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- An appointment hero, service finder, and clinician carousel.
- Care-pathway guidance, trust signals, locations, and a booking panel.
- Portable demo content you can seed in one step.

## Good to know

- Built on **Foundation Theme** - install that first.
- Booking, events, and resource sections light up when Bookings, Events, and Blog are installed.
- **Preview** to see it before visitors do.
