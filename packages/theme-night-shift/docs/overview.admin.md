## What this theme gives you

A sleek, near-black look for software products and platforms. It gives your site a refined, product-led direction tuned for system and automation tools.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Night Shift** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- System heroes, workflow rails, and planning roadmaps.
- Changelog, integrations, and security-proof sections.
- Product UI shells and activity timelines with portable demo content.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Your text and images stay yours; the theme only changes the design.
