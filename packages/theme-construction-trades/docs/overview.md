# Theme Construction Trades

<!-- prettier-ignore-start -->

## What this theme gives you

A solid, trustworthy look for builders, contractors, and construction firms. It gives your site a practical, credibility-first direction.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Construction Trades** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Page styles suited to a construction or trades site.
- Portable demo content to start from.
- Colours and fonts tuned for the trades look, all editable in Theme settings.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Pairs well with Form Builder for quote requests.
