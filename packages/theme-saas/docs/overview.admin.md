## What this theme gives you

A product-led storefront for software and subscription businesses. It gives your site an activation-first direction tuned to turn visitors into trials and demos.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Theme SaaS** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- An activation-first hero, metric and logo proof, and a plan-comparison and pricing layout.
- An ROI calculator, docs onboarding, and a demo-request flow.
- Portable demo content to start from.

## Good to know

- Built on **Foundation Theme** - install that first.
- Pairs with Form Builder for demo and trial capture, and Document Lifecycle for in-theme docs.
- **Preview** to see it before visitors do.
