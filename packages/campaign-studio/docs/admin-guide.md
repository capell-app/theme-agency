# Using Campaign Studio

This guide is for editors who build marketing campaigns and owners deciding how to measure them. Every step uses the labels you see on screen.

## Using Campaign Studio (editor how-to)

### How to create a campaign group

1. Go to **Campaign Studio**.
2. Create a **Campaign group** and name it for the campaign (for example "Summer Sale 2026").
3. Add the pages that belong to the campaign.

### How to add a call to action

1. Edit a campaign page.
2. Add a **CTA widget** (call to action), or a **Campaign hero** or **Campaign lead form**.
3. Set its text and where the button goes, then save.

### How to set a conversion goal

1. Open the campaign's **Conversion goals**.
2. Define what counts as a conversion (for example a form submission or a purchase).
3. Save. The dashboard now measures against that goal.

### How to read the dashboard

1. Open the **Campaign overview**.
2. See visits, conversions, and how each page is doing.
3. Use it to decide which pages to keep or improve.

## Rolling out Campaign Studio (for owners)

### Turn on first

- **One campaign with a clear conversion goal.** Define success before you build, so the dashboard means something from day one.

### Add when needed

| Need | Enable |
| --- | --- |
| Compare two versions of a page | A page variant, once you have enough traffic |
| Capture leads on a campaign | A **Campaign lead form** |

### Don't enable yet

- Don't run A/B variants until your traffic is high enough to tell them apart. Start with a single clear page.

### Who does what

| Role | First useful screen |
| --- | --- |
| Editor | The campaign pages and their **CTA** widgets |
| Site owner | **Campaign overview** and **Conversion goals** |

## Troubleshooting for editors

| What you see | What it means | What to do |
| --- | --- | --- |
| The dashboard shows no conversions | No conversion goal is set, or it isn't being met | Define a **Conversion goal** and confirm the action it tracks |
| A campaign page isn't measured | It isn't in the campaign group | Add it to the **Campaign group** |
| A CTA button goes nowhere | Its link isn't set | Open the **CTA widget** and set its destination |
