# Theme Case Study Platform

<!-- prettier-ignore-start -->

## What this theme gives you

A professional, creative look for case-study and project portfolios. It gives creators a polished way to present work, process, and credits.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Case Study Platform** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Creator heroes, discipline filters, and project feeds.
- Media stacks, credits, tools, process notes, and related projects.
- Hiring call-to-action sections and portable demo content.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Your text and images stay yours; the theme only changes the design.
