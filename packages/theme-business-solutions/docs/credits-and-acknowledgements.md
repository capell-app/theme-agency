# Credits And Acknowledgements

Theme Business Solutions builds on the Capell Core theme registry and Foundation Theme rendering contracts.

- Capell Core supplies package discovery, theme definition data, and admin theme surfaces.
- Foundation Theme supplies the shared runtime contract used by renderer-only theme packages.
- Demo Kit supplies deterministic demo content for screenshots and visual documentation.
- Layout Builder supplies the content block editing workflow used to prove unique page content remains editable in the admin.

The initial business theme directions were informed by the Stitch design board created for the Capell business solution theme work.
