# Experiments

<!-- prettier-ignore-start -->

## What it does for you

Experiments lets you test two versions of a page to see which works better. You set up an experiment with variants, send a share of visitors to each, and pick the winner once enough people have seen both.

## Your screens

- **Experiments**: your tests and their status.
- **Variants**: the versions being compared.

## What you can do

- Start an A/B test with two or more variants.
- Set how much traffic each variant gets.
- See how each variant is performing.
- Pick the winner.

## Where to find it

Go to **Experiments** in the admin to set up and read tests.

## Good to know

- Test two versions of a page to see which performs better.
- Pick the **winner** only once enough people have seen both versions.
- Use the **traffic percentage** to control how many visitors take part.
