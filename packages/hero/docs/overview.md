# Hero

<!-- prettier-ignore-start -->

## What it does

Hero provides the hero and banner block, the large headline area at the top of a page.

## Do I need to do anything?

Usually no. It works automatically once installed. You will see its effect as a hero block you can add when building a page.

## Where it shows up

In **Layout Builder**, as a hero or banner block you can add and edit like any other widget.

## Good to know

- There is nothing to switch on; the hero block appears in the block list.
- Edit its headline, image, and buttons the same way you edit any widget.
