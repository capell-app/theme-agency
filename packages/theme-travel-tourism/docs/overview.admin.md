## What this theme gives you

An inviting look for tour operators and travel agencies. It gives your site a vivid, destination-led direction.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Travel & Tourism** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Page styles suited to a travel or tourism site.
- Portable demo content to start from.
- Colours and fonts tuned for the travel look, all editable in Theme settings.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Pairs well with Form Builder and Bookings for enquiries and trips.
