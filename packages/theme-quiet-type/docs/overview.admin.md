## What this theme gives you

A classic, type-led look for publications, journals, writers, and essayists. It gives your site an elegant, reading-first direction.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Quiet Type** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Page styles suited to a publication or writer's site.
- Portable demo content to start from.
- Colours and fonts tuned for the editorial serif look, all editable in Theme settings.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Pairs well with Blog for your articles.
