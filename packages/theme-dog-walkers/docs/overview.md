# Theme Dog Walkers

<!-- prettier-ignore-start -->

## What this theme gives you

A warm, trust-led look for independent dog walkers, sitters, and small neighbourhood pet-care teams. It gives your site a friendly, local feel.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Dog Walkers** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Page styles suited to a pet-care service site.
- Portable demo content to start from.
- Colours and fonts tuned for the warm, local look, all editable in Theme settings.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Pairs well with Bookings and Form Builder for enquiries.
