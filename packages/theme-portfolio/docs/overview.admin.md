## What this theme gives you

A polished look for creators and consultants. It gives your site a portfolio direction for work, case studies, services, media kits, and newsletters.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Theme Portfolio** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Page styles for work, case studies, services, and media kits.
- Portable demo content to start from.
- Colours and fonts tuned for the portfolio look, all editable in Theme settings.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Pairs well with Newsletter for sign-ups.
