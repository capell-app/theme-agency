# Theme Commerce

<!-- prettier-ignore-start -->

## What this theme gives you

A premium, editorial look for retail and e-commerce storefronts that should feel like a buying journey, not a brochure. Warm, image-led styling guides visitors toward a purchase.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Editorial Commerce** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- An image-led hero, product finder, and collection and product grids.
- Comparison, proof, and buying-guide sections with conversion call-to-actions.
- Portable demo content to start from.

## Good to know

- Built on **Foundation Theme** - install that first.
- Pairs with Shopify Commerce for connected-catalogue merchandising, and with Blog for buying guides.
- **Preview** to see it before visitors do.
