# Theme Podcast Show

<!-- prettier-ignore-start -->

## What this theme gives you

A lively look for podcasts, audio shows, and interview series. It gives your site an audio-first direction tuned for episodes and listeners.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Podcast Show** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Page styles suited to a podcast or audio show site.
- Portable demo content to start from.
- Colours and fonts tuned for the podcast look, all editable in Theme settings.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Pairs well with Blog for episode notes.
