# Theme Experimental Directory

<!-- prettier-ignore-start -->

## What this theme gives you

A bold, creative-industry directory look with confident type and a tight grid. It gives your site an art-directed direction for showcasing submissions and winners.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Experimental Directory** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Oversized project titles, status badges, and image-led feature blocks.
- Latest submissions, winners, collections, and profiles.
- Resources and sponsor modules with portable demo content.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Your text and images stay yours; the theme only changes the design.
