# Theme Devtool OSS

<!-- prettier-ignore-start -->

## What this theme gives you

A clean look for open-source developer tools and self-host plus cloud products. It gives your site a credible, developer-friendly direction.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Devtool OSS** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Page styles suited to an open-source developer tool site.
- Portable demo content to start from.
- Colours and fonts tuned for the devtool look, all editable in Theme settings.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Your text and images stay yours; the theme only changes the design.
