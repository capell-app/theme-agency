# Theme Conference Event

<!-- prettier-ignore-start -->

## What this theme gives you

A lively look for conferences, summits, and multi-track events. It gives your site a clear, schedule-friendly direction tuned for attendees.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Conference Event** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Page styles suited to a conference or event site.
- Portable demo content to start from.
- Colours and fonts tuned for the event look, all editable in Theme settings.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Pairs well with Events if you list sessions and registrations.
