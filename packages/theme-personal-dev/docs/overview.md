# Theme Personal Dev

<!-- prettier-ignore-start -->

## What this theme gives you

A clean look for developer personal sites, writers, and bloggers. It gives your site a simple, content-first direction.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Personal Dev** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Page styles suited to a personal or blogging site.
- Portable demo content to start from.
- Colours and fonts tuned for the personal-dev look, all editable in Theme settings.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Pairs well with Blog for your articles.
