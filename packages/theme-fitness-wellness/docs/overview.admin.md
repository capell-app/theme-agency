## What this theme gives you

An energetic look for boutique gyms and fitness studios. It gives your site a motivating, class-led direction.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Fitness & Wellness** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Page styles suited to a gym or fitness studio site.
- Portable demo content to start from.
- Colours and fonts tuned for the fitness look, all editable in Theme settings.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Pairs well with Bookings for classes and sessions.
