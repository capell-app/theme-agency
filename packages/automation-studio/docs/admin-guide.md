# Using Automation Studio

This guide is for owners and operators who build simple automations. Every step uses the labels you see on screen.

## What you're looking at

| Screen or signal | What it tells you |
| --- | --- |
| **Rules** | Your automations and whether they are on |
| An **Action** | What a rule does when it triggers |
| **Run history** | Each time a rule ran, and whether it succeeded |
| **Failed** | A rule run that didn't complete |

## What to do when...

| Situation | What to do |
| --- | --- |
| You want a routine task automated | Build a rule: pick the trigger, then the **Action** (for example **Create note** or send an email) |
| You're not sure a rule is right | Use **Test rules** before turning it on |
| A rule misbehaves | **Pause** it (don't delete) while you check the **Run history** |
| A run shows **Failed** | Open it; use **Replay** once you've fixed the cause |

## Settings and retention

- Pausing a rule keeps it for later; deleting removes it entirely.
- Check **Run history** to confirm a new rule does what you expect before relying on it.
