# Automation Studio

<!-- prettier-ignore-start -->

## What it does for you

Automation Studio runs simple "when this happens, do that" rules for you. For example, when a form is submitted, send an email. You build a rule, see every time it ran, and pause it whenever you like.

## Your screens

- **Rules**: your automation rules and whether they are on.
- **Run history**: every time a rule ran.

## What you can do

- Build a rule: when X happens, do Y.
- Test a rule before relying on it.
- See every time a rule ran.
- Pause a rule without deleting it.

## Where to find it

Go to **Automation Studio** in the admin to build and review rules.

## Good to know

- When a form is submitted, send an email, automatically.
- See every time a rule **ran**, so you can confirm it is working.
- **Pause** a rule without deleting it when you want to stop it temporarily.
