# Theme Knowledge

<!-- prettier-ignore-start -->

## What this theme gives you

An editorial, resource-library look for knowledge bases, publishers, and content-led teams. It gives your site a clear, browsable direction for lots of content.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Theme Knowledge** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Page styles suited to a knowledge base or content library.
- Portable demo content to start from.
- Colours and fonts tuned for the knowledge look, all editable in Theme settings.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Pairs well with Knowledge Base and Blog.
