# Theme Education

<!-- prettier-ignore-start -->

## What this theme gives you

A clear, friendly look for education providers, training teams, and learning programmes. It gives your site a course-and-school direction tuned for learners.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Theme Education** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Page styles suited to a school, course, or training site.
- Portable demo content to start from.
- Colours and fonts tuned for the education look, all editable in Theme settings.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Pairs well with Events and Form Builder for enrolments and enquiries.
