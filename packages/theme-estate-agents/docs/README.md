# Theme Estate Agents Docs

Theme Estate Agents is a premium property renderer for Capell sites. It owns public presentation for property search, featured listings, valuation CTA, local guide, agent team, viewing request, market proof, standard proof, listings, CTA, navigation, and footer sections.

## Files

- [Overview](overview.md)
- [Screenshots](screenshots.json)
- Marketplace assets in `docs/assets/marketplace/`

## Verification

From the repository root, run `vendor/bin/pest packages/theme-estate-agents/tests`. This package does not ship its own PHPUnit config.
