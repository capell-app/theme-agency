## What this theme gives you

A premium look for new-build developers and housebuilders. It gives your site a polished, development-led direction.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Property Developer** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Page styles suited to a new-build or housebuilder site.
- Portable demo content to start from.
- Colours and fonts tuned for the developer look, all editable in Theme settings.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Pairs well with Form Builder for enquiries.
