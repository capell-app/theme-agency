# Theme Raw Index

<!-- prettier-ignore-start -->

## What this theme gives you

A deliberately raw, independent-archive look with monospace type and stark links. It gives your site a distinctive, low-key direction for archives and zines.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Raw Index** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Submission links, interview markers, and archive dates.
- Language notes and zine annotations.
- Fast, simple public pages with portable demo content.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Your text and images stay yours; the theme only changes the design.
