# Theme Character Portfolio Index

<!-- prettier-ignore-start -->

## What this theme gives you

A selective, slightly playful look for a curated portfolio index. It gives your site standout headlines and curated grids to show off the best work.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Character Portfolio Index** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Showcase headlines, category tabs, and curated grids.
- Standout notes, creator summaries, and recommendations.
- Newsletter sections and portable demo content.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Your text and images stay yours; the theme only changes the design.
