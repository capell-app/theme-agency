# Using Frontend Optimizer

This guide is for owners and operators. Every step uses the labels you see on screen.

## What you're looking at

| Screen or signal | What it tells you |
| --- | --- |
| Optimizer settings | Which speed-up options are on |
| Optimised files | The streamlined versions visitors download |

## What to do when...

| Situation | What to do |
| --- | --- |
| A page looks wrong after a big change | Clear the optimised files so they rebuild |
| You're unsure about a setting | Leave the safe defaults on; ask your developer before changing advanced ones |
| The site feels slow | Confirm optimisation is on; raise persistent slowness with your developer |

## Settings and retention

- Optimisation runs automatically. You rarely need to touch it.
- Clearing optimised files is safe; they rebuild as visitors load pages.
