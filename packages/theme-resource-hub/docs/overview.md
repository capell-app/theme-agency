# Theme Resource Hub

<!-- prettier-ignore-start -->

## What this theme gives you

A bright look for landing-page inspiration and education hubs. It gives your site a search-led direction tuned for examples, templates, and courses.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Resource Hub** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Search-led heroes, category shortcuts, and website examples.
- Templates, courses, and books.
- Consent-friendly embeds and resource archives with portable demo content.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Pairs well with Knowledge Base and Blog.
