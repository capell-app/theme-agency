## What this theme gives you

A technical look for developer infrastructure products. It gives your site a precise, engineering-led direction tuned for platform and tooling pages.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Developer Infrastructure** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Platform pillars, command blocks, and deploy timelines.
- Docs and changelog modules, integrations, and architecture diagrams.
- Enterprise call-to-actions and technical feature lists with portable demo content.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Your text and images stay yours; the theme only changes the design.
