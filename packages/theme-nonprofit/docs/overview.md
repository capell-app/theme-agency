# Theme Nonprofit

<!-- prettier-ignore-start -->

## What this theme gives you

An impact-led look for charities and civic organisations. It gives your site a warm direction tuned for campaigns, donations, and volunteering.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Theme Nonprofit** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Page styles suited to a charity or civic site, with campaign and community stories.
- Portable demo content to start from.
- Colours and fonts tuned for the nonprofit look, all editable in Theme settings.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Pairs well with Form Builder and Payments for sign-ups and donations.
