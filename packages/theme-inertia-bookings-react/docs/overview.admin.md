## What this theme gives you

The React component pack for the Theme Inertia Bookings theme. On its own it has nothing to operate; it supplies the React building blocks that theme uses.

## How to use it

1. Install it alongside **Theme Inertia Bookings** and **Capell Inertia**.
2. Activate **Theme Inertia Bookings** from **Appearance > Themes** as usual.
3. This pack is used automatically; there is no separate screen to open.

## What it adds

- The React components the Inertia Bookings theme renders with.

## Good to know

- Built on **Foundation Theme** - install that first.
- Choose this pack if your site runs on React; use the Vue pack instead for Vue.
- There is nothing to configure here directly; settings live in the Inertia Bookings theme.
