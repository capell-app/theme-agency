## What this theme gives you

A solid, industrial look for manufacturers and smart factories. It gives your site a capable, capability-led direction.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Manufacturing** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Page styles suited to a manufacturing or industrial site.
- Portable demo content to start from.
- Colours and fonts tuned for the manufacturing look, all editable in Theme settings.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Pairs well with Form Builder for enquiries.
