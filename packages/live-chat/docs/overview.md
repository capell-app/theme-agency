# Live Chat

<!-- prettier-ignore-start -->

## What it does for you

Live Chat puts a chat box on your site so visitors can talk to your team. You set the hours you are available, show an offline message after hours, and read past conversations.

## Your screens

- **Chat sites**: where chat is turned on.
- **Availability windows**: the hours your team is available.
- **Conversations**: past chats you can read.

## What you can do

- Turn on chat for your site.
- Set the hours your team is available.
- Show an offline message after hours.
- Read past conversations.

## Where to find it

Go to **Live Chat** in the admin to set availability and read conversations.

## Good to know

- Set the hours your team is **Available**, so visitors know when to expect a reply.
- Show an offline message after hours so visitors can still leave their details.
- Read past **conversations** to follow up on leads.
