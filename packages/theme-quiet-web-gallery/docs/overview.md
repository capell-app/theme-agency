# Theme Quiet Web Gallery

<!-- prettier-ignore-start -->

## What this theme gives you

A calm web-design gallery look with light greys and modest type. It gives your site an understated browse-first direction.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Quiet Web Gallery** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Practical browse panels and understated image grids.
- Latest showcase entries, category archives, and best-of lists.
- Sponsor space and newsletter paths with portable demo content.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Your text and images stay yours; the theme only changes the design.
