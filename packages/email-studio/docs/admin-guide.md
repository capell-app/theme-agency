# Using Email Studio

This guide is for editors who brand the emails customers receive and owners deciding what to change. Every step uses the labels you see on screen.

## Using Email Studio (editor how-to)

### How to edit and brand a template

1. Go to **Email Studio** and open the template you want (for example the welcome email).
2. Edit its content and apply your branding (logo, colours, wording).
3. Save the template.

### How to preview a template

1. With the template open, use **Preview**.
2. Check how it looks before any customer receives it.

### How to send a test

1. Send a test version of the template to yourself.
2. Confirm the content, links, and branding are right before going live.

### How to check the message log

1. Open the **Message log**.
2. Find the email in question and see whether it was sent and **Opened**.
3. Use this when a customer says an email didn't arrive.

## Rolling out Email Studio (for owners)

### Turn on first

- **Branding the core templates.** Edit the everyday emails (welcome, password reset) and test them before relying on them.

### Add when needed

| Need | Enable |
| --- | --- |
| Confirm delivery and engagement | Open tracking (**Track opens**) |
| Try wording changes safely | Template variants |

### Don't enable yet

- Don't change a template customers depend on without a test send first. These emails are transactional.

### Who does what

| Role | First useful screen |
| --- | --- |
| Editor | **Email templates**: edit and brand |
| Site owner | **Message log**: confirm delivery |

## Troubleshooting for editors

| What you see | What it means | What to do |
| --- | --- | --- |
| A customer says an email didn't arrive | It may have failed or gone to spam | Check the **Message log** for that email's status |
| The email looks unbranded | The template wasn't saved, or the wrong one was edited | Re-open the correct template, apply branding, and save |
| A test email looks broken | A content or link issue in the template | Fix it, preview again, and re-test before going live |
| Opens show as zero | Open tracking is off, or the email wasn't opened | Confirm **Track opens** is on |
