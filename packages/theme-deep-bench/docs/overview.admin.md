## What this theme gives you

A clean portfolio directory look. It gives your site a browse-first direction for showcasing many portfolios.

## How to use it

1. Go to **Appearance > Themes** (or **Settings > Theme**).
2. Choose **Deep Bench** and **Activate**.
3. Open **Theme settings** to set your logo, colours, and fonts.
4. **Preview** before making it live.

## What it adds

- Directory heroes, role filters, and portfolio grids.
- Featured portfolios, profile details, and gallery pages.
- Articles, curated lists, and related portfolios with portable demo content.

## Good to know

- Built on **Foundation Theme** - install that first.
- **Preview** to see it before visitors do.
- Your text and images stay yours; the theme only changes the design.
